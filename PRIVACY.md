# Политика конфиденциальности HomeBabyMonitor

**Действует с 8 ноября 2026 года. Применяется к экспериментальной версии 0.3.1.**

HomeBabyMonitor («Домашняя няня») — приложение для обмена звуком и видео между двумя Android-телефонами в одной локальной сети. Разработчик проекта: [Kronv3rk на GitHub](https://github.com/Kronv3rk). Вопросы по конфиденциальности: [создать обращение в репозитории](https://github.com/Kronv3rk/home-baby-monitor/issues/new). **Не публикуйте в обращениях изображения ребёнка, пароли, коды сопряжения, домашний IP-адрес или другие персональные данные.**

## Какие данные использует приложение

- **Камера и микрофон:** приложение получает изображение и звук с выбранного телефона для передачи подключённому родительскому телефону по локальной сети. Родительский телефон использует микрофон при нажатии кнопки обратной связи.
- **Локальные сетевые сведения:** IP-адреса устройств, служебные сообщения обнаружения и подключения, данные WebRTC (SDP/ICE), случайный код сопряжения и временные криптографические ключи для установления соединения.
- **Сведения об устройстве:** уровень заряда, состояние зарядки, состояние соединения, событие продолжительного громкого звука.
- **Управление камерой:** команды включения ночного режима и фонарика, если они поддерживаются устройством.

Приложение запрашивает разрешения Android на камеру, микрофон, локальную сеть и уведомления; также использует foreground service, wake lock и Wi-Fi lock. Разрешения применяются в указанных выше целях.

## Куда передаются данные

В текущем исходном коде **нет учётных записей, аналитики, рекламы, облачных сервисов, внешнего сервера сигнализации или сервера записи**. Медиа передаются непосредственно между двумя устройствами с использованием WebRTC. Служебное обнаружение происходит через UDP, а сигнализация — через локальный TCP с шифрованием. Для установления соединения приложение не настраивает внешние STUN/TURN-серверы.

**Разработчик не получает изображение, звук, историю наблюдения и код сопряжения через собственные серверы.** Данные доступны подключённым устройствам в пределах работы соединения. Интернет-разрешение Android необходимо также для локальных сетевых сокетов.

Это описание относится к исходному коду версии 0.3.1. Оно не является гарантией отсутствия ошибок, компрометации сети, ошибок ОС или незаявленного поведения сторонних компонентов. Для стороннего форка или изменённого APK действуют правила его распространителя.

## Хранение и удаление

В версии 0.3.1 не реализованы запись видео и звука, загрузка файлов наблюдения в облако и серверная история событий. Буферы звука, изображения, адреса и ключи используются во время сеанса; отдельной пользовательской базы с историей наблюдения приложение не создаёт. Системные журналы Android и временные данные библиотек могут обрабатываться самой операционной системой.

Для завершения обработки остановите сеанс и закройте приложение. Для удаления локальных данных приложения используйте системные настройки Android → Приложения → Домашняя няня → Хранилище → Очистить данные либо удалите приложение. Поскольку у приложения нет сервера и учётной записи, удаление данных через разработчика не предусмотрено.

## Безопасность

- Сопряжение выполняется по случайному коду, который пользователь переносит с первого телефона на второй.
- Сигнализация защищена AES-256-GCM, медиа — средствами WebRTC (DTLS-SRTP).
- Использовать приложение рекомендуется только в доверенной домашней сети с защищённым Wi-Fi.
- Меры защиты не прошли независимый аудит. Не используйте приложение как единственный способ наблюдения за ребёнком.

## Дети и другие люди в кадре

Приложение предназначено для взрослых лиц, осуществляющих уход за ребёнком. Следите за соблюдением прав членов семьи, гостей и иных лиц, попадающих в кадр. Использование камеры вне личной домашней обстановки, в отношении посторонних лиц или в профессиональных целях может требовать дополнительных уведомлений и правовых оснований в вашей юрисдикции.
