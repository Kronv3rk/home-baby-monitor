# HomeBabyMonitor

Видеоняня для двух Android-телефонов в одной Wi-Fi-сети. Один телефон передаёт изображение и звук, второй показывает трансляцию и принимает предупреждения. Подключение к интернету и учётная запись не нужны.

> **Статус: экспериментальная версия 0.3.2.** APK собирается в CI, но работа на разных телефонах, устойчивость при выключенных экранах и надёжность тревог пока не проверены. Не используйте приложение как единственный способ наблюдения за ребёнком.

## Возможности

- Видео 640 × 480 до 20 кадров/с и звук через WebRTC.
- Поиск камеры в домашней сети; при необходимости — подключение по IP.
- Сопряжение по случайному коду с экрана камеры. Сигнализация шифруется AES-256-GCM.
- Обратная связь с ребёнком по кнопке, состояние батареи телефона с камерой.
- Предупреждения о продолжительном громком звуке, остановке видеокадров и потере связи.
- Повторное подключение при обрыве; попытка сохранить передачу звука при погашенном экране.
- Программное повышение яркости изображения и управление фонариком, если камера телефона это позволяет.

**Детектора именно детского плача нет.** Приложение реагирует на уровень и продолжительность звука; телевизор, разговор или шум могут вызвать такое же предупреждение. Ночной режим не заменяет инфракрасную камеру.

## Установка

Готовые тестовые APK доступны в [Releases](https://github.com/Kronv3rk/home-baby-monitor/releases) и в артефактах [GitHub Actions](https://github.com/Kronv3rk/home-baby-monitor/actions). Сборки пока подписываются временным debug-ключом: новая сборка может потребовать удаления предыдущей версии.

1. Установите одинаковый APK на два телефона с Android 8.0 или новее.
2. Подключите устройства к одной домашней Wi-Fi-сети. Гостевая сеть с изоляцией устройств не подойдёт.
3. На первом телефоне запустите режим **«Камера ребёнка»** и выдайте необходимые разрешения.
4. На втором выберите **«Родительский телефон»**, введите код с экрана камеры. Если автоматический поиск не сработал, укажите IP камеры вручную.
5. Проверьте реальное воспроизведение звука и видео, затем — предупреждение при отключении Wi-Fi и работу с погашенными экранами.

Не кладите телефон и зарядный кабель в кроватку или в пределах досягаемости ребёнка. Учитывайте нагрев телефона при продолжительной работе камеры.

## Сборка из исходников

Требуются JDK 17, Android SDK Platform 36 и Gradle 8.13. Откройте корень репозитория в Android Studio либо выполните:

```bash
gradle :app:testDebugUnitTest :app:lintDebug :app:assembleDebug
```

APK появится в `app/build/outputs/apk/debug/app-debug.apk`. Для локальных тестов протокола достаточно установленного Kotlin CLI:

```bash
bash tools/verify-jvm.sh
```

GitHub Actions выполняет Android unit-тесты, Lint и сборку APK при изменениях в `main` и в pull request. Результаты проверок приведены в [VALIDATION.md](VALIDATION.md). Аппаратные испытания этими тестами не заменяются.

## Устройство проекта

| Каталог | Назначение |
|---|---|
| `app/src/main/java/com/homebabymonitor/core/` | Протокол, шифрование сопряжения, контроль звука и связи |
| `app/src/main/java/com/homebabymonitor/net/` | Поиск устройств, TCP-сервер и клиент сигнализации |
| `app/src/main/java/com/homebabymonitor/rtc/` | WebRTC, камера и обработка видеокадров |
| `app/src/main/java/com/homebabymonitor/ui/` | Экраны и компоненты Jetpack Compose |
| `MonitorService.kt` | Фоновая служба наблюдения и уведомления |
| `app/src/test/`, `tools/` | Android unit-тесты и локальные интеграционные проверки |

Медиа передаются между телефонами напрямую, без STUN/TURN и облачного сервера. Сигнализация идёт по TCP-порту 43182, обнаружение — по UDP-порту 43183. В текущей версии нет записи видео, облачных аккаунтов и аналитики.

Протокол сопряжения разработан для этого приложения и **не проходил независимый криптографический аудит**. Не используйте приложение в недоверенных или публичных сетях.
