# Вклад в HomeBabyMonitor

Исправления отправляйте через pull request с описанием проблемы и результата. Для изменений протокола, работы камеры, фонового режима, тревог и шифрования необходимы тесты. Указывайте модель телефона и версию Android, если проверяли на устройстве.

Не прикладывайте к публичным issue или PR домашние IP-адреса, ключи подписи, коды сопряжения и фото либо записи ребёнка. Уязвимости передавайте приватно по [SECURITY.md](SECURITY.md). Изменения обработки данных должны сопровождаться правкой [PRIVACY.md](PRIVACY.md).

Публикуйте только материалы, на которые имеете права. Изменения собственного кода предлагаются на условиях [MIT](LICENSE); лицензии сторонних компонентов сохраняются.
